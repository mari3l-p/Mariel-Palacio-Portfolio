# Mariel's Frontend Developer Portfolio

Welcome to the repository for my personal portfolio! I am a Frontend Developer with 3 years of professional experience, and this site serves as a central hub to showcase my client work, coding challenges, and continuous learning journey.

**[View Live Portfolio](https://mariel-palacio-portfolio.vercel.app/)**

## Tech Stack

This project is bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) and built using modern web technologies:

*   **Framework:** [Next.js](https://nextjs.org) (App Router)
*   **Library:** [React](https://reactjs.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Email API:** [Resend](https://resend.com/) (Server-side API route for the contact form)

## Features

*   **Project Showcase:** A curated selection of my web development work, including client projects (like The Vape Kings and Können Studio) and vanilla JavaScript applications.
*   **Certifications Section:** Highlights of my ongoing education, including credentials from Harvard University (CS50), freeCodeCamp, and HackerRank.
*   **Functional Contact Form:** A fully working, secure contact form that sends messages directly to my email using a Next.js backend API route and the Resend SDK.
*   **Fully Responsive:** A mobile-first design that scales elegantly across all device sizes.
